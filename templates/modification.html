Viva / Practical Concept: What is Database Modification?

Database modification can occur at two levels:
1. Structural Modification (DDL): Uses ALTER TABLE to add new columns, remove obsolete columns, rename attributes, or alter datatypes without losing existing table data.
2. Data Manipulation (DML): Uses UPDATE or DELETE to modify the values stored inside table tuples.
